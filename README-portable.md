# TDock 0.1.21 免安装版

TDock 为 Windows 10 原生任务栏添加图标悬停放大、点击弹跳和居中。使用环境为 Windows 10 22H2 x64 的经典主屏底部任务栏，动画需要已适配的 Explorer 构建。

## 使用方法

完整解压 ZIP，将 `TDock.exe` 和 `TDockNative.dll` 保留在同一目录。双击 `TDock.exe`，再点击系统托盘里的 TDock 图标打开设置。旧版 Windhawk TaskDock 模组用户请先停用该模组。

首次运行默认开启「动画」和「居中」。已保存的开关设置优先。「开机自启」默认关闭，可在托盘菜单中开启。

## 彻底删除免安装版
在解压目录中双击 `TDock-Uninstall.exe`，确认路径后点「卸载」。默认会清除保存的设置，重新安装时想保留原来的设置可以取消勾选。卸载器会退出这份 TDock、清理它的自启快捷方式和运行缓存，并删除压缩包里随附的文件。目录中的其他文件、改动过的文件和下载的 ZIP 会保留。仅当默认解压目录已经空了，才会移除该目录。

如果还有缓存 DLL 被占用，卸载器会先移除这份程序文件，再给出两个选项。

- 「重启资源管理器并完成」会先请你确认，再尝试重启当前会话的 Windows 资源管理器并清理缓存。请先完成正在进行的文件操作。
- 「下次登录自动清理」会为当前 Windows 用户登记一次性任务。注销后重新登录，任务会清理本次记录的缓存和临时清理工具。

关闭选项窗口时，完成提示会给出临时清理工具的位置，方便稍后继续。目录中的备份文件和下载的 ZIP 会保留。

### 手动清理

卸载器无法运行时，按以下步骤处理。

1. 打开 TDock 托盘面板，关闭「开机自启」，再点「退出 TDock」。如果程序已删掉或无法启动，在资源管理器地址栏输入 `shell:startup`，检查 `TDock` 快捷方式的目标，删除指向这份免安装版的 `TDock.lnk`（扩展名可能隐藏）。
2. 删除解压出来的 TDock 文件。如果单独解压到了一个目录，可以删除该目录。下载的 ZIP 如还保留，也可以删除。
3. 在资源管理器地址栏输入 `%LOCALAPPDATA%\TDock`，删除其中的 `Runtime` 文件夹。若系统提示文件正在使用，在任务管理器里选中「Windows 资源管理器」并点「重新启动」，然后重试。清理完成后，可删除空的 `TDock` 文件夹。
4. 若要同时清除保存的设置，打开「注册表编辑器」，进入 `HKEY_CURRENT_USER\Software\TDock`。删除右侧的 `EffectsEnabled`、`CenterTaskbar` 和 `ClickDurationMs` 三个值。若只使用过免安装版，且该项已空，可以一并删除 `TDock` 项。
